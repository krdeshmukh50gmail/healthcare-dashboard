Healthcare Data Analysis Dashboard | Power BI

Project Overview
The Healthcare Data Analysis Dashboard is an interactive Power BI project designed to explore healthcare data and present key metrics in a clear, visual format. It helps users review patient demographics, hospital performance, admissions, and revenue-related metrics.

Objectives
- Analyze patient and hospital-related data.
- Track important healthcare KPIs in one place.
- Compare patient records across categories such as gender, admission type, and medical condition.
- Use interactive filters to explore data and support data-driven decisions.
Tools & Technologies
- Power BI Desktop — dashboard development and visualization
- Power Query — data cleaning and transformation
- DAX — calculated measures and calculations
- Data Modeling — organizing data for analysis
Key Performance Indicators (KPIs)
The dashboard includes the following KPI cards, depending on the selected filters:
- Total Patients
- Total Revenue
- Average Age
- Average Length of Stay
- Total Doctors
- Total Hospitals
Dashboard Features
- Interactive KPI cards
- Charts for exploring healthcare data
- Slicers/filters for Year, Hospital, Gender, Admission Type, and Medical Condition
- Age-group analysis to compare patient groups
- Filter interactions that update the displayed metrics and visuals
Age Grouping
Patients can be grouped into age bands to make demographic comparisons easier:
- 0–18
- 19–35
- 36–50
- 51–65
- 65+

Project Workflow
1. Imported the healthcare dataset into Power BI.
2. Reviewed the fields and checked data types.
3. Cleaned and transformed the data in Power Query.
4. Created calculated columns and/or DAX measures where needed.
5. Built KPI cards, charts, and slicers.
6. Tested filter interactions and reviewed the dashboard for readability.

- How do patient counts vary by hospital, gender, or admission type?
- How does total revenue change across the available categories?
- What does the age-group distribution look like?
- How do average age and average length of stay vary under different filters?

How to Use
1. Download or clone this repository.
2. Open the .pbix file using Microsoft Power BI Desktop.
3. If prompted, update the dataset source path or credentials.
4. Refresh the data if the original dataset is available.
5. Use the slicers to interact with the report.
